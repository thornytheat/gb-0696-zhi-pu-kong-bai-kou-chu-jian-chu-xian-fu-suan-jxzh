# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白按（批次，检测项，稀释倍数）分组，样品只配对同稀释组空白中位数；组缺失时样品隔离（BLANK_GROUP_MISSING），整项无空白时隔离（BLANK_MISSING）。净浓度允许为负；不能提前截零。检出限=max(3×组内标准差,0.05)×样品稀释倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

空白修订按（批次，检测项）登记，须含全部所需稀释组的空白复测行。修订序号只增不退：旧序号拒绝，同序号异值隔离，同序号同值重办不新增。修订启用后仅重算待复核批次；已复核批次保留当时的空白、检出限和限定符。修订范围内有样品配不到空白组则该批切换失败，保留原结果并记录原因。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。
